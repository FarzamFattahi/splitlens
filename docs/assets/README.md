# SplitLens brand artwork

`splitlens-banner.png` is the repository header. It is illustrative brand artwork, not an application screenshot or analysis result. Actual workspace screenshots live in `docs/screenshots/`.

Created with the built-in image-generation tool. The final generation prompt was:

> Premium GitHub README banner for SplitLens, an image dataset auditing tool for computer vision. Wide landscape, approximately 2:1. Warm off-white backdrop, charcoal typography, cobalt blue accent, subtle fine grid. Exact title “SplitLens”; headline “Better data. Before training.”; supporting line “Find duplicates, split leakage & image-quality issues.”; labels “Browser workspace” and “Python library + CLI”. Elegant overlapping image contact sheets with ceramic cups and one matched pair connected across sheets by a blue line. Balanced whitespace, crisp typography, matte paper, soft natural shadows, central text safe zone. No fake UI screenshots, fabricated metrics, badges, gradients, neon, robots, watermark, or extra text.

The artwork is included under the repository's MIT license. Reuse it with the project identity intact; do not present its illustrative photographs as audited dataset evidence.
